# ComfyBIOWMS Web Extensions

This directory contains the web frontend assets loaded by ComfyUI when `WEB_DIRECTORY = "./web"` is exposed in the root `__init__.py`.

## Contents
- `js/comfybio_main.js`: Main LiteGraph extension script that applies domain color coding, badges, and lifecycle hooks for bioinformatics nodes.
- `css/comfybio.css`: Stylesheet for custom UI widgets and visualizer previews.
